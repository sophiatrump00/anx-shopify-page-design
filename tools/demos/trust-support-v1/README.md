# 信任与售后 Demo 01

独立的 A3 交互原型，供讨论购买区保障、售后申请与型号支持体验。不是 Shopify 模板，不改变正式店铺。

启动：在仓库根目录运行 `python3 -m http.server 8796 --bind 127.0.0.1 --directory tools/demos/trust-support-v1`，打开 `http://127.0.0.1:8796/`。

## 可以体验

- 手机/桌面预览；四张保障卡片展开政策说明。
- 政策说明进入带型号和问题类型的申请页。
- 问题分类、条件必填、申请预览、返回修改。
- 快速上手、故障排查、联系支持。

所有表单只保存在本页内存，页面刷新即清空；无发送接口、埋点、外部字体或购物请求。页面 CSP 阻止网络连接及原生表单发送。邮件链接由用户自行操作；完整政策链接打开公开网站。

## 依据与待办

政策文案依据 2026-11-05 会话中线上读回：`/pages/warranty`、`/pages/return-policy`、`/pages/shipping-policy`、`/pages/contact-us`。五年保修仅用于 A3 跳启示例，不推及 RV 电池或家储。图片复制自仓库现有 A3 素材；价格是当日 PDP 快照，不连接实时价格。未展示存在冲突的峰值电流等参数。

正式接入前仍需确认型号资料、各产品保修范围、客服收件及回复能力；本 demo 不代表这些事项已完成。

浏览器检查：390px 手机单一售价位置、320px 申请页/资料页无横溢出；保修申请类型带入、条件必填、本地预览和返回编辑、FAQ 展开、外层导航同步。仅浏览器模拟，非真实手机验收。
