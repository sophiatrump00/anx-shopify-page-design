# SuntNeew PDP 整页故事 Demo v2

独立交互样板，用于讨论购买区、视觉、卖点顺序和支持入口的整体修改。包含 A20 启动电源与 G31 房车电池两页；不代表其他产品已经完成改版。家储不在本轮范围。正式 Shopify 主题未修改、未发布。

## 打开

- 统一预览器：<http://127.0.0.1:8797/?product=a20&device=desktop>
- 手机模式：<http://127.0.0.1:8797/?product=a20&device=mobile>
- G31：<http://127.0.0.1:8797/?product=g31&device=desktop>
- 独立产品页：`product.html?product=a20` 或 `product.html?product=g31`

顶部可切换产品和设备；切换设备时回到产品顶部。图库、图片放大、功能页签、数量、本地购物车、参数、FAQ、保障条款和手册可以操作。

在主题仓库根目录启动：

```bash
python3 -m http.server 8797 --bind 127.0.0.1 --directory tools/demos/pdp-story-v2
```

当前机器已启动临时用户服务 `suntneew-pdp-story-demo-v2.service`，仅监听 `127.0.0.1:8797`。可用 `systemctl --user status suntneew-pdp-story-demo-v2.service` 检查，`systemctl --user stop suntneew-pdp-story-demo-v2.service` 停止。服务在用户会话退出或机器重启后可能需要重新启动。

旧版源码保留在 `tools/demos/trust-support-v1/`，本版独立保存。

## 设计方向

整页结构以 [Renogy Pro S1](https://www.renogy.com/products/pro-s1-12v-120ah-240ah-lifepo4-battery) 为单一主要参考：清楚的购买区 → 场景大图 → 用户收益 → 功能与可靠性 → 使用/安装 → 随箱与规格 → 评价 → 保障与 FAQ。英文文案、产品信息与图片使用 SuntNeew 自有资料，不移植竞品的参数、测试、评价或承诺。

- A20：从无法启动时的随车备用，讲到适配、夹钳指示、设备供电和收纳。
- G31：从房车日常用电，讲到容量、状态监控、安装空间和正确使用。
- 使用同一套黑白灰、橙色按钮、图片比例和文字层次；按两类产品调整故事。
- 购买区直接呈现五年有限保修、14 天符合条件的退货、美国适用地区免邮和终身技术支持。点击再看条件。
- 主价格完全滚出屏幕后才出现底部购买条，返回时隐藏。
- 手机预览框的内容视口为 390px，外框另计。另检查独立页 320px 和 390px 视口。

## 内容来源和边界

`content-sources.json` 记录产品库、现站快照和设计参考；`asset-sources.json` 记录原图路径、SHA-256、尺寸与处理。源路径相对于业务工作区或主题仓库，原件未修改。

产品参数来自业务工作区的 `新能源独立站产品知识库_v2.sqlite3`，对照现站与产品手册使用。A20 固定 8,000mAh 橙色配置；G31 固定 12.8V 100Ah。Demo 未实现其他容量、颜色、库存或变体切换。

价格和评价为本轮保存的现站快照：A20 $49.99、4.7/18；G31 $240、5.0/2。比较价分别为 $59.99、$329.99。它们没有连接实时 Shopify 数据；评价节选来自同一产品现站，未添加“已验证购买”标记。正式实施须改回真实产品对象和评价组件。

图片与两本手册来自现有主题资产。场景、安装和 App 图包含既有合成/示意素材，不作为现场测试、实际安装或真实 App 界面验证。移除了页面中的蓝色发光内部剖面图；A20 充电图裁掉容易混淆输入与输出的 PD18W 嵌字。USB-C 输入与 USB-A 输出在正文分别说明。裁切没有修改产品参数或原件。

A20 视频沿用现站 YouTube `cZLH2Q9gKlc`，保留 Canyon Life on Amazon Live 来源；只说明展示套件、夹钳和接口，没有把演示升级为独立测试背书。已确认视频弹窗和播放器载入，未完成从头到尾播放验收。

服务文字以本轮政策快照为依据：仅美国本土 48 州和 Washington, DC；2 个工作日处理、出库后预计 2–5 个工作日运输，周一至周五。未改退货窗口、未新增保险或人工全天候响应承诺，也未修改后台配送设置。

**G31 保修仍有正式实施缺口：**现站 G31 产品页说明五年有限保修，独立 `/pages/warranty` 目前只覆盖启动电源。本 Demo 的 G31 细则入口指向已存在的 `/pages/support-rv-g31`，不套用启动电源的排除条款。上线前须补全/核准 G31 型号细则，并统一 PDP、支持页和政策页链接；Demo 不代表这一生产缺口已经修复。

## 技术与验证

无构建依赖和外部字体。图片、脚本、样式和手册在本目录。产品页 CSP 禁止联网购物请求和表单提交；视频仅点击后加载 YouTube 无 Cookie 域名。购物车只存在当前页面内存，弹窗明确提示本地演示；刷新或切换产品后清空，不创建真实购物车、订单或支付。

浏览器检查记录见 `qa-results.json`。已检查两产品桌面/手机布局、图库放大、页签及键盘导航、数量与演示小计、底部加购、保障弹窗、FAQ/更多参数、预览器同步和回顶部。3 个脚本语法检查通过；24 个资产原件哈希匹配，22 张 WebP 解码通过，31 个本地资源 HTTP 200。

这些是浏览器模拟和机械检查，未进行真实手机、Safari、多浏览器、支付或正式发布验收。本轮只新增 `tools/demos/pdp-story-v2/`，不涉及 Liquid/JSON 主题改动。仓库现有 26 项测试和结构检查通过；Theme Check 为 0 个错误、8 个警告（既有主题警告，本轮未清理）。这些回归结果不代表线上主题发布或生产购物链路验收。
