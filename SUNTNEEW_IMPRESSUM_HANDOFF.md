## Page template

The theme includes `templates/page.impressum.json`. In Shopify Admin:

1. Create or open the page titled `Impressum`.
2. Set the URL handle to `impressum`.
3. Select the `page.impressum` template (it may appear as `impressum`).
4. Paste the approved English copy below into the page editor, then preview and publish.

Once the page exists, the theme's Company footer column adds the page link automatically when the menu does not already contain an Impressum link. If the menu already contains one, the theme avoids adding a duplicate.
