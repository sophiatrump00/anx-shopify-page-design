# SuntNeew SEO audit remediation — 2026-09-08

Source: `suntneew_08-sep-2026_all-issues_2026-09-08_05-27-48` Site Audit export.

The audit is a snapshot, not a list of independent faults. The 404 and 4XX
exports overlap, as do the noindex, nofollow and slow-response exports.

## Changes

- Corrected 24 native Shopify theme translations that translated URL structure
  into nonexistent paths. Kept the original source digest checks. Added a
  preparation tool for future URL-translation reviews.
- Internal contact and shipping-policy links in the calculator, QR support and
  certificate library now retain the Shopify-generated language prefix. Existing
  localized URLs, external URLs and document links are preserved.
- Set `seo.hidden = 1` (integer) on the existing `quotes-history` page. It remains
  available as a functional page but is excluded from native search and sitemap.
- Added 343 WebP variants for 61 bundled RV gallery/detail images. Original
  artwork is retained. Full-resolution WebP totals 11.33 MB versus 50.49 MB for
  the source files. The 960px variants total 5.27 MB; 160px thumbnails total
  0.34 MB. These totals describe the complete asset set, not one page load.
- Galleries now serve responsive images and small thumbnails. Zoom continues
  to use the full-resolution image, and the first gallery image retains eager
  loading and high fetch priority. Detail pages retain mobile artwork choices.
- Added localized descriptions for the journal, patents, QR support, shipping
  and returns in eight languages. Native Shopify SEO descriptions take
  precedence. Short Japanese text is no longer replaced by an English fallback,
  and automatic body excerpts are shortened at word boundaries rather than replacing curated descriptions.
- Preserved the current live theme's localization/editor changes in a separate
  Git commit before applying these fixes. Original uncommitted work in the main
  local checkout was not discarded.

## What the image report actually measured

All 22 reported Shopify **Files** image URLs returned WebP when requested with
browser image-format support. The largest response was 195,310 bytes. The
reported 11,261,343-byte `width=4000` configuration image returned a 59,426-byte
WebP. Those original-format crawler measurements do not establish that a
browser downloads the PNG. CDN resizing and format negotiation remain enabled;
product source media and zoom detail were not removed to clear a crawler flag.

Bundled theme assets need separate treatment: they are served in their uploaded
format. The new variants address that real delivery issue.

## Sitemap and indexing review

All 32 current product/page/collection/blog sitemaps across eight languages
returned valid XML. There were no duplicate listed URLs, and no quote-history
URLs remained. Of the 181 previously missing URLs, 165 now appear in sitemap.
The remaining 16 are `/collections/all` and `/policies/shipping-policy` in eight
languages. Shopify does not normally list these generated routes; sitemap
absence alone is not an indexing defect.

The old duplicate-sitemap report referenced two different `from`/`to` ranges for
the same Shopify page sitemap. The current root sitemap lists one current range
per language; it does not require a custom replacement sitemap.

The default English URL appearing once as `en` and again as `x-default` is
valid. Native Shopify hreflang is retained, rather than duplicated in Liquid.
PDF assets with `X-Robots-Tag: none`, search pages with noindex, and HTTP/domain
redirects with no internal incoming links are not treated as content failures.
No paid SEO app, IndexNow subscription, or DNS change was introduced.

## Reproducing checks

Run `node tools/validate-theme.mjs` from the theme root. For rendering tests,
install `liquidjs@10.29.0` into a temporary directory and set `LIQUIDJS_MODULE`
to its `dist/liquid.node.mjs` before running `node --test tools/seo-theme.test.mjs`.
`tools/optimize-storefront-assets.py` uses Pillow and the explicit tracked source
list. `tools/audit-storefront.py` rechecks an export at a conservative request
rate and stops on HTTP 429; do not treat blocked requests as healthy pages.
