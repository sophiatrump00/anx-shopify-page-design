## What the image report actually measured

All 22 reported Shopify **Files** image URLs returned WebP when requested with
browser image-format support. The largest response was 195,310 bytes. The
reported 11,261,343-byte `width=4000` configuration image returned a 59,426-byte
WebP. Those original-format crawler measurements do not establish that a
browser downloads the PNG. CDN resizing and format negotiation remain enabled;
product source media and zoom detail were not removed to clear a crawler flag.

Bundled theme assets need separate treatment: they are served in their uploaded
format. The new variants address that real delivery issue.

## Reproducing checks

Run `node tools/validate-theme.mjs` from the theme root. For rendering tests,
install `liquidjs@10.29.0` into a temporary directory and set `LIQUIDJS_MODULE`
to its `dist/liquid.node.mjs` before running
`node --test tools/seo-theme.test.mjs tools/shogun-integration.test.mjs tools/arabic-locale.test.mjs`.
`tools/optimize-storefront-assets.py` uses Pillow and the explicit tracked source
list. `tools/audit-storefront.py` rechecks an export at a conservative request
rate and stops on HTTP 429; do not treat blocked requests as healthy pages.
